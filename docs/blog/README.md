# Published drafts

Adaptations of `docs/positioning.md` and `docs/what-shipping-payments-taught-us.md`
for LinkedIn. They live here so the published wording is versioned next to the
source it came from, rather than existing only in a paste buffer.

**These will drift, and that is expected.** The source documents are written for
someone with the repository open; these are written for someone who has never
heard of it. When the source changes materially, decide deliberately whether the
published version needs a correction — do not sync them mechanically.

## What changed in adaptation

- **The opening.** Each leads with the finding rather than with the project,
  because LinkedIn truncates at roughly 200 characters and the first two lines
  decide whether anything else is read.
- **Repo context removed.** No file paths, no "this repository", no assumed
  knowledge of what x402 is.
- **The table went.** `positioning.md` measures the coupling in a table;
  LinkedIn does not render one, so it became prose.
- **Paragraphs shortened**, because it is read on a phone.

## One correction that mattered

`what-shipping-payments-taught-us.md` says _"It leads the x402 Global Challenge
leaderboard."_ That was true when written. It is not now — the service sits at
rank 64 of 1,479 tagged entries, with 17 settles against a leader on 236,998.

The claim is cut from the published version. It is the kind of thing that gets
checked, and being caught overstating costs more than the claim was ever worth.

The source document still carries it. Fix it there too, or date it.
